# ☕ Cafe Website

## 📌 About the Project

A modern and responsive cafe website designed to provide visitors with an attractive and user-friendly browsing experience. This project is developed using HTML, CSS, and JavaScript.

## 🛠️ Technologies Used

- HTML5 – For website structure.
- CSS3 – For styling and layout.
- JavaScript – For interactive functionality.

## 🚀 How to Run the Project

You can view the live project directly here: [Live Demo](https://alisha-rehman.github.io/Alisha-s-cafe/)

Alternatively, to run it locally:

1. Clone or download this repository.
2. Open the project folder.
3. Double-click the `index.html` file.
4. The website will open in your default web browser.

**Note:** For the best experience, use a modern browser like Google Chrome or Mozilla Firefox.

## 📁 Project Files

- `index.html` – Main HTML structure.
- `style.css` – Website styling.
- `script.js` – JavaScript functionality.
